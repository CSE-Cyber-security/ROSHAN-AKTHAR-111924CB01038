# Python Programs - Week 3

This repository contains simple Python programs for Week 3 tasks.

## Programs

Fibonacci Series (`fibonacci.py`)
Prints the Fibonacci series for n terms.

**Sample Run**
```
Enter the number of terms: 7
Fibonacci Series:
0 1 1 2 3 5 8
```

## How to Run
```
python fibonacci.py
```
