Python Factorial Calculator
A simple Python script to calculate the factorial of a given number using an iterative approach.

Features
Iterative Calculation: Uses a for loop for efficient computation without hitting recursion depth limits.

Edge Case Validation: Safely handles negative number inputs and base cases (0 and 1).

Usage
Ensure you have Python installed on your system.

Save the code into a file named factorial.py.

Run the script from your terminal:

Bash
python factorial.py
Example Output
Plaintext
The factorial of 5 is 120
Production Alternative
If you are using this in a larger project rather than for learning purposes, Python's built-in math module is the standard, optimized approach:

Python
import math
print(math.factorial(5))
